## About

AI_HRMS is a comprehensive Human Resource Management System that leverages artificial intelligence and modern web technologies to manage HR operations efficiently. The system provides a robust backend built on Spring Boot with Java 17, ensuring scalability and reliability for enterprise-level HR operations.

## Features

- 🎯 **Employee Management** - Comprehensive employee data management
- 📊 **Analytics & Reporting** - Data-driven HR insights and reports
- 🔒 **Data Validation** - Input validation and data integrity checks
- 🗄️ **Database Integration** - MySQL database support for persistent storage
- 📱 **RESTful API** - Well-structured API endpoints for seamless integration
- 🧪 **Testing** - Unit and integration testing capabilities

## Tech Stack

### Backend
- **Language**: Java 17
- **Framework**: Spring Boot 4.0.7
- **Build Tool**: Maven
- **Database**: MySQL
- **ORM**: Spring Data JPA
- **Validation**: Spring Validation
- **Development Tools**: Lombok, Spring DevTools

### Testing
- Spring Boot Test Suite
- JPA Testing Support
- Security Testing
- Web MVC Testing

## Prerequisites

Before you begin, ensure you have the following installed:

- **Java 17** or higher
- **Maven 3.6+**
- **MySQL 8.0+** (or compatible version)
- **Git**
